Qwen2.5-Omni-7B 文本转语音部署指南

4. 构建对话（纯文本输入） conversation = system_prompt + [ {"role": "user", "content": [{"type": "text", "text": text_input}]} ] # 5. 处理输入数据 text = processor.apply_chat_template(conversation, add_generation_prompt=True, tokenize=False) audios, images, videos = process_mm_info(conversation, use_audio_in_video=False) #
